Para onde vai o dinheiro

  • Primeiro objetivo: uma bateria eletrônica. O RudiMaster nasceu do meu estudo no pad, e o próximo passo é levar isso para o kit completo, melhorando a ferramenta com o que eu aprender no caminho.
  • Manter a ferramenta aberta e gratuita para quem estuda, sem exigir cadastro nem pagamento.
  • Domínio e hospedagem, que são os custos fixos de deixar o site no ar.
  • Tempo de desenvolvimento: rudimentos novos, rotinas de treino salvas e histórico de andamento.
  • Cada contribuição estica o tempo que o projeto consegue seguir sem depender de outra fonte de receita.

Formas de ajudar sem gastar nada

  • Mande o link para o seu professor, para a banda ou para o grupo de bateria.
  • Conte o que está faltando. Feedback de quem treina de verdade é o que direciona o que vem depois.
  • Se achou um erro em algum rudimento, avise. Notação errada atrapalha estudo.
